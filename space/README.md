# ContextLib

A read-only view of the sample ContextLib library: the invented **lighthouse-app** harbor dashboard.

`index.html` loads `library.json` in the browser. `build.py` rebuilds that JSON from `examples/sample-library` using the core Library API (project meta, every record's meta and body, and `BRIEF.md`).

Open the project brief, search records, and follow supersession links. Nothing on this page is writable. The Markdown files remain the source of truth.

ContextLib is the open library layer of AgentBrain (agentrooms.io).
